# Gmod_Lua_Extractor

Распаковщик клиентских Lua-скриптов из кэша Garry's Mod.

Когда вы заходите на сервер, игра сохраняет присланные сервером клиентские
Lua-файлы в `garrysmod/cache/lua` в сжатом виде (LZMA, формат `util.Compress`).
Эта утилита находит папку кэша, распаковывает файлы в читаемый `.lua` и убирает
дубликаты. **В процесс игры она не внедряется и ничего в неё не грузит** — это
отдельная программа, которая только читает уже сохранённые на диске файлы.

## Сборка

```sh
cargo build --release
```

Готовый бинарник: `target/release/gmod_lua_extractor` (на Windows — `.exe`).

## Использование

```sh
# автопоиск кэша через библиотеки Steam, вывод в ./extracted_lua
gmod_lua_extractor

# явный путь и своя папка вывода
gmod_lua_extractor "C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\cache\lua" -o out
```

Параметры:

| Параметр | Значение |
|---|---|
| `ПАПКА_КЭША` | путь к `cache/lua`; без него ищется автоматически |
| `-o, --output ПАПКА` | куда сохранить скрипты (по умолчанию `./extracted_lua`) |
| `--keep-duplicates` | не пропускать файлы с одинаковым содержимым |
| `-v, --verbose` | подробный вывод |
| `-h, --help` | справка |

## Как это работает

- Содержимое файла кэша — это 5 байт свойств LZMA + 8 байт размера + поток
  `.lzma` (ALONE). Перед ним может стоять служебный заголовок (4 байта CRC32 в
  старых версиях, 32 байта SHA-256 в новых), поэтому декодер пробует несколько
  смещений и проверяет, что результат похож на текст.
- Папка кэша ищется во всех библиотеках Steam через `libraryfolders.vdf`.
- Одинаковые по содержимому скрипты сохраняются один раз (сравнение по SHA-1).

## Ограничения

- Утилита достаёт только то, что сервер уже прислал и игра сохранила в кэш.
  Она не обходит серверные запреты и не загружает скрипты в игру.
- Поддерживаются обычные для кэша Lua форматы (LZMA `util.Compress` и
  несжатый текст). Нестандартно упакованные файлы попадут в список ошибок.
